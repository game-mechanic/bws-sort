COMMON CLICK ISSUES & SOLUTIONS:
---------------------------------

Issue: Some Bubbles Not Clickable
----------------------------------
Cause 1: Missing Collider
  → Fixed! Now auto-added

Cause 2: Bubbles Behind Other Colliders
  Solution:
  1. Check sorting layers
  2. Ensure bubbles are on top layer
  3. Adjust Z position if needed

Cause 3: Collider Too Small
  Solution:
  1. Select bubble in Play mode
  2. Check CircleCollider2D radius
  3. Increase if needed (default 0.5f)

Cause 4: Physics Blocking Clicks
  Solution:
  1. Check if Rigidbody2D is sleeping
  2. Collider might be disabled
  3. Check "Is Trigger" is OFF

Issue: No Click Feedback
-------------------------
Check Console Messages:
  • "TreeBubble clicked..." should appear
  • If not appearing, collider issue
  • If appearing but not moving, slot issue

Issue: Clicks Work on Some, Not Others
---------------------------------------
Possible Causes:
1. Those bubbles already in slots (check slottedBubbles list)
2. Those bubbles have disabled colliders
3. Those bubbles are behind camera

Solution:
  • Enable Gizmos in Scene view
  • Select each bubble, check Inspector
  • Verify CircleCollider2D is enabled

PREFAB REQUIREMENTS:
--------------------

Your TreeBubble prefab must have:

Root GameObject:
├─ TreeBubble (script) ✓ Required
├─ CircleCollider2D ✓ Auto-added if missing
├─ Rigidbody2D (added at runtime)
└─ SpringJoint2D (added at runtime)

Child GameObjects:
├─ Background (SpriteRenderer) - Assign to bgRenderer
├─ Icon (SpriteRenderer) - Assign to iconRenderer
├─ Text (TextMeshPro) - Assign to textLabel
├─ Highlight (GameObject) - Assign to highlightEffect
└─ Chain (LineRenderer) - Assign to chainLine

If any visual is missing, bubble still works but may look wrong.
