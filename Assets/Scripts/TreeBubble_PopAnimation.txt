═══════════════════════════════════════════════════════════════════

ANIMATION SEQUENCE:
-------------------

Step 1: Bubble Movement (0.5s)
-------------------------------
• 4th matching bubble is clicked
• Bubble moves to slot with OutBack easing
• DOTween animation: 0.5 seconds
• User sees bubble traveling to complete the match

Step 2: Match Check (0.6s delay)
---------------------------------
• Wait 0.6 seconds for movement to complete
• CheckForMatches() called
• Detects 4 matching categories
• Triggers pop sequence

Step 3: Pop Animation (Per Bubble)
-----------------------------------
Staggered timing: 0.1s delay between each bubble

For Each Bubble:
  a) Anticipation (0.15s)
     • Scale up to 1.3× current size
     • Ease: OutQuad (smooth acceleration)
     • Prepares viewer for the pop
  
  b) Pop! (0.2s)
     • Scale up to 2.0× current size
     • Ease: InBack (pulls back slightly then explodes)
     • Dramatic expansion
  
  c) Particle Burst
     • Triggered at peak of scale
     • ParticlePool.PlayRevealFx() called
     • Bubble destroyed immediately after
  
Step 4: Cleanup
---------------
• All 4 bubbles destroyed
• Remaining bubbles shift left (0.3s)
• Slots refilled sequentially

CUSTOMIZATION OPTIONS:
----------------------

Want Faster Pops?
-----------------
In PopBubbles() method:

// Reduce anticipation time
.DOScale(..., 0.1f)  // was 0.15f

// Reduce pop time
.DOScale(..., 0.15f)  // was 0.2f

// Reduce stagger
float delay = i * 0.05f;  // was 0.1f


Want More Dramatic?
-------------------
// Bigger anticipation
.DOScale(bubble.transform.localScale * 1.5f, ...)  // was 1.3f

// HUGE pop
.DOScale(bubble.transform.localScale * 3f, ...)  // was 2f


Want Simultaneous Pops?
-----------------------
// Remove stagger
float delay = 0f;  // was i * 0.1f

All bubbles pop at once (less satisfying but faster)


Want Instant Pops?
------------------
In HandleBubbleClicked():

// No delay
CheckForMatches();  // Remove DOVirtual.DelayedCall

Back to instant behavior (not recommended)

SEQUENCE STRUCTURE:
-------------------

DOTween.Sequence() used for coordination:

Main Sequence (popSequence):
├─ Bubble 0 Pop Sequence (delay 0.0s)
│  ├─ Scale up to 1.3× (0.15s)
│  ├─ Scale up to 2.0× (0.2s)
│  └─ Callback: Particle + Destroy
│
├─ Bubble 1 Pop Sequence (delay 0.1s)
│  ├─ Scale up to 1.3× (0.15s)
│  ├─ Scale up to 2.0× (0.2s)
│  └─ Callback: Particle + Destroy
│
├─ Bubble 2 Pop Sequence (delay 0.2s)
│  └─ [same as above]
│
├─ Bubble 3 Pop Sequence (delay 0.3s)
│  └─ [same as above]
│
└─ Final Callback: Shift remaining bubbles

All sequences run in parallel (Join),
each with its own delay for stagger effect.

═══════════════════════════════════════════════════════════════════

EASING FUNCTIONS EXPLAINED:
----------------------------

OutBack:
  • Used for: Movement to slot
  • Effect: Overshoots then settles
  • Feeling: Bouncy, playful arrival

OutQuad:
  • Used for: Anticipation scale
  • Effect: Starts slow, accelerates
  • Feeling: Smooth, natural growth

InBack:
  • Used for: Pop scale
  • Effect: Pulls back, then explodes forward
  • Feeling: Spring-loaded, dramatic

OutQuad (shift):
  • Used for: Bubble shift after pop
  • Effect: Fast start, smooth stop
  • Feeling: Quick but controlled

TROUBLESHOOTING:
----------------

Issue: Bubbles Pop Before Reaching Slot
----------------------------------------
Cause: Delay too short

Fix:
// Increase delay in HandleBubbleClicked()
DOVirtual.DelayedCall(0.8f, () => CheckForMatches());  // was 0.6f


Issue: Bubbles Don't Pop At All
--------------------------------
Check:
□ Console shows "✨ MATCH!" message
□ All 4 bubbles are same category
□ DOTween imported in project

Debug:
• Add Debug.Log in PopBubbles() start
• Verify method is being called


Issue: Pop Animation Too Fast/Slow
-----------------------------------
Adjust timing in PopBubbles():
• Anticipation duration (0.15s)
• Pop duration (0.2s)
• Stagger delay (0.1s)

See Customization Options above


Issue: Particles Not Appearing
-------------------------------
• Check ParticlePool initialized
• Verify GameSettings has BubbleFXPrefab
• See TreeBubble_ParticleSetup.txt

Animation still plays without particles!
