ISSUE: "Category: null" when clicking bubbles
----------------------------------------------

This means the BubbleType is not being assigned or preserved properly.

═══════════════════════════════════════════════════════════════════

DIAGNOSTIC STEPS:
-----------------

Step 1: Check Console During Spawn
-----------------------------------
After clicking [Spawn Bubbles In Editor], check Console for:

✓ "Spawning bubble X: Category='Colors', Icon=True, Text=''"
  → Category is being assigned correctly

✗ "Spawning bubble X: Category='', Icon=False, Text=''"
  → Category assignment is failing

✗ "Skipping bubble X - no valid category found!"
  → No valid categories in CategoryBubbles list


Step 2: Check Bubble Inspector
-------------------------------
1. Select TreeBubbleManager in Hierarchy
2. Expand to see child bubbles
3. Select a bubble (e.g., TreeBubble_0_Colors)
4. Check Inspector → TreeBubble component:

Look for:
  Runtime Data
  └─ Assigned Category: [Should show BubbleType name]

If "Assigned Category" is None/Empty:
  → Category not being set during Initialize()


Step 3: Check CategoryBubbles List
-----------------------------------
1. Select TreeBubbleManager
2. Inspector → Category Bubbles section
3. Expand each entry

For each entry, verify:
□ Category field has a BubbleType assigned (not None)
□ Icon OR Text has a value
□ BubbleType is a valid ScriptableObject

If Category shows "None":
  → Create BubbleType: Right-click → Create → BubbleType
  → Assign it to the Category field


Step 4: Validate BubbleType Assets
-----------------------------------
1. Find your BubbleType assets in Project
2. Select one (e.g., "Colors")
3. Inspector should show:
   - Script: BubbleType
   - Name: Colors (or whatever you named it)
   - Material: (optional)

If asset is missing or broken:
  → Right-click in Project → Create → BubbleType
  → Name it appropriately
  → Assign to CategoryBubbles list

═══════════════════════════════════════════════════════════════════

COMMON CAUSES:
--------------

Cause 1: CategoryBubbles List Empty
------------------------------------
Symptom: "No category bubbles defined!"

Fix:
1. Select TreeBubbleManager
2. Inspector → Category Bubbles
3. Set Size = at least 1
4. Expand Element 0
5. Assign Category, Icon, and/or Text


Cause 2: Category Field Not Assigned
-------------------------------------
Symptom: "CategoryBubbleData[0] has null category!"

Fix:
1. Create BubbleType asset if needed
2. Drag BubbleType to Category field
3. Click [Validate Setup] to verify


Cause 3: BubbleType Asset Missing
----------------------------------
Symptom: Category field shows "Missing (BubbleType)"

Fix:
1. Create new BubbleType:
   Project → Right-click → Create → BubbleType
2. Name it (e.g., "Colors", "Animals", "Foods")
3. Assign to Category field


Cause 4: Serialization Issue (Editor → Play)
---------------------------------------------
Symptom: Works in Editor, null in Play mode

This is fixed by the serialized field:
  [SerializeField] BubbleType assignedCategory;

The category is now preserved when entering Play mode.


Cause 5: Multiple BubbleType Instances
---------------------------------------
Symptom: Names look same but don't match

Fix:
1. Ensure using SAME BubbleType instance
2. Not creating duplicates
3. All bubbles of "Colors" use same Colors asset

SUMMARY OF FIXES APPLIED:
--------------------------

✓ Added serialized field: assignedCategory
  → Persists category across Editor/Play transition

✓ Category property fallback:
  public BubbleType Category => category ?? assignedCategory;
  → Returns assignedCategory if category is null

✓ Awake() restoration:
  if (assignedCategory != null && category == null)
      category = assignedCategory;
  → Restores category on Play mode start

✓ Initialize() stores both:
  category = cat;
  assignedCategory = cat;
  → Double-stores for safety

✓ Validation logging:
  → Shows category during spawn
  → Shows category during click
  → Easy to spot null values
