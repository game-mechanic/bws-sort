STEP-BY-STEP WORKFLOW:
-----------------------

1. SETUP (One-time)
-------------------
□ Create TreeBubble prefab with visuals

2. VALIDATE
-----------

------------------
□ Click [Spawn Bubbles In Editor]
□ Check Console: "✓ Spawned X/X bubbles"
□ Verify bubbles visible in Scene view
□ Adjust settings if needed

4. TEST LAYOUT
--------------
□ Move Scene camera to see all bubbles
□ Check green circle gizmo (spawn boundary)
□ Select individual bubbles to see collider (green sphere)
□ Verify no complete overlaps
□ Chains should connect bubbles to anchors

5. ENTER PLAY MODE
-------------------
□ Click Play button
□ Bubbles start swinging (physics active)
□ NO new spawning occurs
□ Editor-spawned bubbles are now interactive

6. GAMEPLAY TEST
----------------
□ Hover over bubble → Highlight appears
□ Click bubble → Console: "TreeBubble clicked..."
□ Bubble moves to first empty slot
□ Click 3 more of SAME category
□ Console: "✨ MATCH! 4 adjacent bubbles..."

□ Remaining bubbles shift left

KEY FEATURES:
-------------

NO AUTO-SPAWN IN PLAY MODE:
  • Bubbles only spawn via [Spawn Bubbles In Editor]
  • Editor bubbles persist into Play mode
  • Physics activates when Play mode starts
  • Click events auto-connect on spawn

MATCHING LOGIC:
  • Checks LAST 4 bubbles in slots
  • All 4 must be same category
  • Pops with particle effects
  • Remaining bubbles shift to fill gaps
  • Console shows match/no-match feedback

COLLISION PREVENTION:
  • Collider radius: 0.45 (adjustable)
  • Slightly smaller than visual (0.5)
  • Prevents complete overlap
  • minDistanceBetweenBubbles: 0.8
  • Visual gizmo shows click area

OVERLAP PREVENTION:
-------------------

Visual Size vs Collider:
  • Bubble visual: ~0.5 radius
  • Collider: 0.45 radius (10% smaller)
  • Gap between colliders: 0.1 minimum
  • Prevents physics overlap

Min Distance:
  • Set in TreeBubbleManager
  • Controls spawn spacing
  • Default: 0.8 (center to center)
  • Collider radius: 0.45 each
  • Total: 0.9 diameter
  • Result: 0.1 gap minimum

Density Check:
  • Validation calculates density
  • Warns if > 1.5 bubbles/unit²
  • Suggests increasing radius
  • Prevents overcrowding

Visual Gizmo:
  • Select bubble in Scene view
  • Green wireframe = collider
  • Shows exact click area
  • Verify no overlap visually

═══════════════════════════════════════════════════════════════════

ADJUSTING COLLIDER SIZE:
-------------------------

If bubbles are hard to click:
  1. Select TreeBubble prefab
  2. Find "Collision" section
  3. Increase "Collider Radius" to 0.5
  4. Respawn bubbles

If bubbles overlap too much:
  1. Decrease "Collider Radius" to 0.4
  2. Increase "Min Distance Between Bubbles" to 0.9
  3. Respawn bubbles

Perfect balance (recommended):
  • Collider Radius: 0.45
  • Min Distance: 0.8
  • Visual Size: 0.5
  • Gap: 0.1

TROUBLESHOOTING:
----------------

Issue: Bubbles spawn on Play
Solution: They shouldn't! Only spawn in Editor now.

Issue: Match not detected
Check: Console shows last 4 categories
Verify: All 4 are SAME BubbleType instance
Fix: Ensure using same ScriptableObject, not copies

Issue: Bubbles overlap visually
Solution: 
  • Increase "Min Distance Between Bubbles"
  • Decrease "Bubble Count"
  • Increase "Radius"

Issue: Bubbles don't pop
Check: Console for match message
Verify: ParticlePool exists in scene
Fix: Add particle system or remove ParticlePool calls

Issue: Clicks not working
Check: Console for "TreeBubble clicked..." message
Verify: CircleCollider2D exists and enabled
Fix: [Validate Setup] will show collider status
