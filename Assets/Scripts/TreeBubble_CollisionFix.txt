1. COLLISION REPELLING FIX:
----------------------------

Problem:
  • Bubbles spawn close together
  • CircleCollider2D on each bubble
  • Physics detects collisions
  • Bubbles push each other away
  • Results in chaotic initial movement

Root Cause:
  • Bubbles have physical colliders (for OnMouseDown)
  • Bubbles have Rigidbody2D (for swinging)
  • Physics engine resolves overlaps by pushing apart

Solution:
  Use Physics2D.IgnoreCollision() for all bubble pairs
  
  In TreeBubbleManager.Start():
    for each bubble A:
      for each bubble B:
        Physics2D.IgnoreCollision(A.collider, B.collider, true)

Result:
  ✓ Bubbles can overlap without repelling
  ✓ OnMouseDown still works (collider active)
  ✓ SpringJoint2D still works (doesn't need collision)
  ✓ Clean initial state
  ✓ No chaotic movement

Why This Works:
  • Colliders still exist (required for mouse input)
  • Physics ignores bubble-to-bubble collisions
  • Bubbles only interact via spring joints
  • Natural hanging behavior achieved

ALGORITHM DETAILS:
------------------

Circle Generation (GenerateCirclePositions):
  1. For each bubble:
     a. Generate random angle (0-360°)
     b. Generate random distance (sqrt for uniformity)
     c. Calculate position from center
     d. Check minimum distance from existing bubbles
     e. If valid, add position
     f. If invalid, try again (up to maxAttempts)
  
  2. Fallback tiers:
     Tier 1: Full min distance
     Tier 2: 70% min distance (relaxed)
     Tier 3: Force placement anywhere

Square Generation (GenerateSquarePositions):
  1. Calculate grid dimensions:
     cols = sqrt(count)
     rows = count / cols
  
  2. Calculate cell size:
     cellWidth = totalWidth / cols
     cellHeight = totalHeight / rows
  
  3. For each grid cell:
     a. Calculate base position (center of cell)
     b. Add random offset (25% of cell size)
     c. Add to positions list
  
  Result: Grid layout with organic variation

COLLISION MATRIX EXPLANATION:
------------------------------

Physics2D.IgnoreCollision(col1, col2, true):
  • Tells Unity physics to ignore col1 ↔ col2
  • Applied to all bubble pairs on Play mode start
  • Permanent for game session
  • Doesn't affect other collisions

Number of Calls:
  For N bubbles: N × (N-1) / 2 collision pairs
  
  Examples:
    10 bubbles: 45 calls
    20 bubbles: 190 calls
    30 bubbles: 435 calls
  
  Performance: Negligible (one-time setup)

Why Not Layers?
  • Would require layer setup in Physics2D settings
  • Less portable between projects
  • IgnoreCollision is simpler
  • Works immediately without config

---------------------

• Increase Square Size (e.g., 6×5 instead of 5×4)
• Decrease Bubble Count
• Increase Min Distance Between Bubbles

---------------------
Solution:
• Decrease Square Size (e.g., 4×3 instead of 5×4)
• Increase Bubble Count
• Keep spacing for visual clarity
